# Renyyt — 快速指南

Renyyt 根据 Renyy（Pirkanmaan Jätehuolto）的 Oma jätehuolto 服务，显示垃圾桶的下一次清运日期。这是非官方客户端。

服务：<https://renyyt.fi/>。自行部署需要 Python 3.8 或更高版本：解压发布包，在其目录中运行 `python3 run.py`，然后打开 <http://127.0.0.1:8787>。

## 基本用法

1. 选择语言，输入 Oma jätehuolto 客户编号和密码，然后点击**获取清运时间**。
2. **垃圾桶**用于选择显示的垃圾桶。在普通视图中，选择**排序 → 自定义顺序**，即可使用箭头或拖放调整顺序。**精简视图**保留顺序并隐藏调整工具。
3. 将下一次清运日期导出为 `.ics` 日历。**嵌入视图**只显示清运信息。安装、反馈和提醒功能取决于服务器设置及浏览器支持。

是否保存登录信息由用户决定。浏览器中的混淆数据并非安全加密；请勿在共用设备上保存登录信息，也不要分享含有登录信息的嵌入链接。提醒依据浏览器上次成功获取的数据。旧的缓存数据会标记为过期。
