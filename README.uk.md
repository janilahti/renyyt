# Renyyt — короткий посібник

Renyyt показує найближчі дати вивезення відходів із сервісу Oma jätehuolto компанії Renyy (Pirkanmaan Jätehuolto). Це неофіційний клієнт.

Сервіс: <https://renyyt.fi/>. Для власного сервера потрібен Python 3.8 або новіший: розпакуйте архів випуску, виконайте в його каталозі `python3 run.py` і відкрийте <http://127.0.0.1:8787>.

## Основне використання

- Виберіть мову, введіть номер клієнта й пароль Oma jätehuolto та натисніть **Отримати дані**.
- **Контейнери** визначає видимі контейнери. **Порядок → Власний порядок** дозволяє переміщати їх стрілками або перетягуванням у звичайному вигляді. **Компактний вигляд** зберігає порядок без кнопок редагування.
- Експортуйте найближчі дати до календаря `.ics`. **Вбудований вигляд** показує лише дані вивезення. Встановлення, зворотний зв’язок і нагадування залежать від налаштувань сервера та підтримки браузера. Для встановлення потрібні збережені номер клієнта й пароль. Введіть їх, увімкніть збереження даних для входу в цьому браузері та натисніть кнопку завантаження дат вивезення.

Збереження облікових даних необов’язкове. Дані в браузері не захищені надійним шифруванням; не зберігайте їх на спільних пристроях і не поширюйте посилання вбудовування з паролем. Нагадування використовують останні успішно отримані браузером дані. Старі збережені дані позначаються як застарілі.
